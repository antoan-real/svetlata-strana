# Светлата страна – Bildablage

Hier liegen die Bilder für die Facebook-Seite „Светлата страна“.

- `posts/<datum>/post.json` – Texte des Karussells
- `posts/<datum>/photo.url` – Link zum (freien) Foto; GitHub lädt es automatisch als `photo.jpg`
- `posts/<datum>/out/1.jpg …` – fertige Folien
- `tools/render.py` – baut die Folien im Design der Seite
